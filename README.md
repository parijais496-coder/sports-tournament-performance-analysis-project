# Sports Tournament Performance Analysis

A Python (pandas) project that analyzes FIFA World Cup match data. It lets you pick a team and instantly see its match history, goals scored, and head-to-head stats.

## Features

- Load World Cup match data from a CSV file
- Enter a team name and view all its matches (home and away)
- Count total matches played by the team
- Calculate total goals scored by the team
- Show the top 10 teams by number of home matches
- Search matches by World Cup year
- Search matches against a specific opponent

## Dataset

- File: `WorldCupMatches[1].csv`
- Key columns used: `Year`, `Home Team Name`, `Away Team Name`, `Home Team Goals`, `Away Team Goals`

## Technologies Used

- Python 3
- pandas
- Google Colab

## How to Run

1. Open the notebook in Google Colab.
2. Upload `WorldCupMatches[1].csv` to the Colab session (Files panel, left side).
3. Run the cell.
4. Enter the inputs when asked:
   - Team name (e.g. `Brazil`)
   - World Cup year (e.g. `2014`)
   - Opponent team name (e.g. `Germany`)
